TENTANG MEDI TRACK PRO

Satu tempat untuk memantau alat medis.

MediTrackPRO merupakan prototype sistem monitoring dan manajemen alat medis yang dikembangkan untuk membantu petugas dalam mengelola informasi alat secara lebih terstruktur.

Sistem ini merupakan pengembangan dari aplikasi berbasis Python dan OOP menjadi prototype web menggunakan HTML, CSS, dan JavaScript.

✓ Informasi alat lebih terorganisir
✓ Monitoring kondisi secara visual
✓ Simulasi penggunaan dan maintenance
